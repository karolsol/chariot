# About
Simple yet powerful self-hosted app to manage your vehicles. It allows you to keep track of your vehicles, their maintenance, and expenses.

# Usage
## Docker
You can run Chariot using Docker. Just run the following command:
```bash
cd docker
docker-compose up -d
```
For production use you **really should** change .env variables to your own values. Also use some kind of reverse proxy to secure your app with HTTPS. You can use Nginx or Traefik for that.
## Bare metal
It is entirely possible to run it without Docker, but it is not supported nor recommended.

# Development
## Requirements
- Node.js and pnpm with version similar to the one used in the project (check package.json)
- PostgreSQL database(or docker to run it)
- A modern web browser

### Installing dependencies
You can do it with your package manager of choice, but I recommend asdf:
```bash
asdf add plugin nodejs
asdf add plugin pnpm
asdf install
asdf reshim
```

### Running the app
1. First of all install dependencies:
```bash
pnpm install
```
2. Next start Postgres database. You can use docker for that:
```bash
docker run -d \
           --name chariot-psql \
           -e POSTGRES_USER=admin \
           -e POSTGRES_PASSWORD=password \
           -e POSTGRES_DB=chariot-dev \
           -p 5432:5432 \
           postgres:latest
```
3. Lastly run development server:
```bash
pnpm dev
```
It is going to hot reload the app on every change. You can access it at http://localhost:5173
### Tests, type-checks and linting
Tests can be run with the following command:
```bash
pnpm test
```
Linting can be run with the following command:
```bash
pnpm lint
```
Type-checking can be run with the following command:
```bash
pnpm type-check
```

### DB migrations
To run database migrations, you can use the following command:
```bash
pnpm -F backend migration:run
```
To create a new migration, you can use the following command:
```bash
pnpm -F backend migration:generate <migration-name>
```
